# NES APU Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the emulator a sound: pulse/triangle/noise APU, frame counter with IRQ, nonlinear mixer, SDL2 output, and blargg's APU test ROMs passing headless.

**Architecture:** A new `apu.rs` owned by `Bus`, clocked one CPU cycle at a time from the bus's existing per-dot tick. `rom.rs` gains mapper 0 (NROM) only so the test ROMs load; `ppu.rs` gains CHR RAM for the same reason; `bus.rs` gains `$6000` PRG RAM, APU register routing, and a warm-reset path. A `#[cfg(test)]` harness module runs the ROMs headless and reports their result codes.

**Tech Stack:** Rust 1.99 stable, edition 2021, `sdl2` 0.38.0 only (audio via `sdl2::audio`'s queue API). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-18-nes-apu-design.md`

## Global Constraints

- Rust edition 2021, stable toolchain. `sdl2 = "0.38.0"` is the only dependency; no dev-dependencies.
- Single crate; tests inline per module under `#[cfg(test)] mod tests`. The ROM harness is `#[cfg(test)] mod apu_rom_test;` in the binary (no library target exists).
- **DMC is fully cut:** `$4010-$4013` writes are dropped, `$4015` bit 4 and bit 7 read 0. `works_immediately` is asserted as an expected failure, code 2.
- Mapper 66 (the SMB cart) must behave exactly as today. Mapper 0 exists only for the test ROMs.
- NTSC only. CPU 1789773 Hz (integer), frame = 29780.5 CPU cycles, 3 PPU dots per CPU cycle.
- No resampler, no audio thread, no WAV oracle. SDL queue + integer sample accumulator only.
- Blargg's measured timings in `test_roms/apu_2005/readme.txt` overrule the NESdev wiki where they disagree. `tests.txt` decodes failure codes.
- ROMs are gitignored; every test that needs one skips when absent (`rom.rs`'s `real_rom()` pattern).
- Commit style: conventional commits, one per task (`feat:`, `refactor:`, `test:`).

## Review Focus

Five failure modes the spec implies; each has a test pinned in its owning task.

1. **`$4017` written inside the two-clock window around a frame step** — mode switch dropped or double-stepped; tempo shifts and ROMs 04/05/06 report "too soon/too late". Tests: Task 4 unit tests, Task 11 ROMs.
2. **`$4015` read/write flag semantics** — read must clear the frame IRQ flag; writes of `$00`/`$80` must not, `$40`/`$C0` must. A wrong answer leaves the IRQ line stuck low. Tests: Task 4 unit tests, Task 11 ROM 03.
3. **SMB handed a live IRQ line it never asked for** — it writes `$4017=$C0`/`$FF` (inhibit) and must never receive an IRQ; a spurious one hangs 1-1. Tests: Task 13 headless SMB run + manual play.
4. **Host stalls the audio device** — queue grows without bound, or the device starves and pops. Tests: Task 8 cap test.
5. **No audio device (CI, headless)** — must run silently, never panic. Tests: Task 10 guard (SDL open failure path), Task 11 runs with no SDL at all.

Mixer, straight from NESdev "APU Mixer" (no DMC term):

```
pulse_out = if p1 + p2 == 0 { 0.0 } else { 95.88 / (8128.0 / (p1 + p2) as f64 + 100.0) }
tnd_out   = if t == 0 && n == 0 { 0.0 } else { 159.79 / (1.0 / (t as f64 / 8227.0 + n as f64 / 12241.0) + 100.0) }
sample    = ((pulse_out + tnd_out) * 32767.0).clamp(0.0, 32767.0) as i16
```

Accumulator: `acc += rate; while acc >= 1_789_773 { acc -= 1_789_773; emit one stereo pair }`, clocked in `tick`.
